# Plugins

Community and third-party plugins that extend untether.

No third-party plugins are listed yet. Untether discovers plugins registered under the `untether.engine_backends`, `untether.transport_backends` and `untether.command_backends` entry-point groups — run `untether plugins` to see what is installed, and see [Write a plugin](../how-to/write-a-plugin.md) to build one.
